## Your three points

**Does every node's `parse` run?** No: a node another constructor removes never runs its `parse`.

```
h := type (share parse_rank = *.parse_rank - 1, share parse = ( print «h ran», tape.is_constructed[0] = true )), g := type (share parse_rank = *.parse_rank + 1, share parse = ( tape.remove(1), tape.is_constructed[0] = true )), g h, 5
```

Output: `5`, never "h ran".

**Can the flag be set automatically after each `parse`?** No: leaving it `false` hands your position to what you put there, whose `parse` runs next.

```
h := type (share parse_rank = *.parse_rank + 1, share parse = ( tape[0] = i32 )), x := h 5, print «{x}»
```

Output: `5`. With the flag `true`, the `5` is left over: `error: expected one expression, found more`.

**Is the flag read only inside a `parse`?** No: the parser reads every node's flag after its `parse`.

```
h := type (share parse = ( print «ran» )), h, 5
```

Output: `ran`, then an error: `h`'s constructor left its own node unbuilt.
