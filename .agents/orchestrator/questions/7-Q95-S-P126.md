Claude Code can run small scripts by itself, called **hooks**: when a session opens or is resumed, when a turn ends, after each tool call. One kind of hook can **wake me even when I am idle**. Hooks written in the repo's `.claude/settings.json` are loaded every time a session opens, after a restart too.

- (a) **Hooks in the repo's own settings file.** When my session opens or is resumed, and at the end of each turn, a hook starts the watch, before my first turn and whatever mode I am in. Your save wakes me at once. A second hook keeps my turn from ending while a file holds a save I have not taken in. A third blocks the question dialog that held my turn for 8 minutes on Q79. In every other session the hooks stop at once. The file is part of the repo, and `setup` writes it for each new repo. About three hours of work; Claude Code may ask you once to approve the file.
- (b) **The same hooks in your own settings file** (`~/.claude/settings.json`). One paste by you serves every repo on this computer, but only this computer.
- (c) **Keep today's watch and enforce the restarts.** I restart it every 30 minutes, which wakes me up to 48 times a day for nothing, and after a computer restart it still waits for my first turn.

Recommended: (a), because nothing has to be done by you or remembered by me, and it travels with the repo.

Opening my session again after a computer restart stays yours; from then on nothing else is needed.
